## 一、需求来源

研究交接文档《研究内容总结_交接文档.md》§4.2 / §5 / §7.2.3 要求：

- 基于 Raw Accel，用 Python 插件**动态改写灵敏度参数**实现 DPI 随时间变化
- 时间驱动自动调度：块模式 800,800,1200,1200 × 30 分钟 + 5 分钟线性渐变
- 2 小时会话上限；对照条件 800 固定 2 小时
- 两档只差 sens：base_dpi=800，sens 1.0 ⇄ 1.5（800 ⇄ 1200 DPI），accel 关闭
- 感度时序列日志 `sens_log_*.csv`（可复现任意时刻有效增益）
- EMG 阈值触发模式（ECU 16% 升 / FDS 20% 降）、交叉点法（模拟版）
- 2 档手动切换 UI、EMG 实时输入接口（external 模式）

## 三、Raw Accel 对接（本工程最关键的调试）

### 3.1 环境事实
- Raw Accel **1.7.0**，装在 `C:\Users\15654\Desktop\RawAccel`
- 写入接口不是 CLI `--write`，而是 **`writer.exe <settings.json 路径>`**
- 1.7 的 settings.json 无 `sens` 字段，灵敏度是 `profiles[0]["Output DPI"]`

### 3.2 关键发现（按发现顺序）
1. **参考插件 `files/` 的实现**：读现有 settings.json → 只改 Output DPI →
   原地写回 → `writer.exe <该文件>`。与我的临时文件写法内容一致，差别只在
   **"是否原地写安装目录的 settings.json"**。
2. **Raw Accel GUI 从不回读驱动**：只显示 settings.json 内容；
   且 `.config` 里 `AutoWriteToDriverOnStartup=true`，每次打开 GUI 会用它
   保存的值覆盖驱动 —— 这是早期"打开 GUI 数值不变"的根因。
3. **驱动回读 API**：wrapper.dll 的 `DriverConfig.GetActive().ToJSON()`
   可读驱动真实配置 → 封装成 `tools/driver_readback.exe` + `--read-driver`。
4. **Sens Multiplier 显示规则 = Output DPI ÷ 1000**（本版本固定）。
5. **驱动防作弊 1 秒延迟**：连续快速写入（<1s 间隔）会被拒绝，writer 返回
   rc=1 —— 这是"按 1200 DPI 改不了"的直接原因。

### 3.3 sens 映射的最终结论
| 档位 | 有效 DPI | 写 Output DPI | Raw Accel GUI 显示 Sens |
|---|---|---|---|
| 800 档（低） | 800 | 1000 | **1.0** |
| 1200 档（高） | 1200 | 1500 | **1.5** |

- 实现：`sens_to_output_dpi(sens) = sens × 1000`
- 有效 DPI = 鼠标硬件 DPI(800) × sens = 800 / 1200
- 早期曾误用 `Output DPI = 800×sens`（显示 0.8/1.2），按用户要求改为 1.0/1.5

### 3.4 桥接层最终写法
- 原地写安装目录 settings.json（保留 devices 等所有字段，只改 Output DPI）
- 调用 `writer.exe` 时**不捕获管道**（DEVNULL），超时杀子进程
- **最小写入间隔 1.1s + 失败重试最多 3 次**（解决防作弊窗口导致的 rc=1）

## 四、踩过的坑速查
1. Tkinter 不支持 8 位带透明度颜色 `#ffffff22` → 用纯色
2. `ttk.Combobox` 无 `command` 参数 → 用 `<<ComboboxSelected>>` 事件
3. 卡片内 grid/pack 混用报错 → 统一放 body 容器
4. bat 文件 LF 换行/中文编码导致 cmd 解析错乱 → CRLF + ASCII
5. 时间加速下引擎每 tick 需按模拟时间 sleep，否则渐变只写 1 步
6. `_apply` 在渐变中途翻转档位导致 EMG 误触发 → 档位只在渐变完成/块边界更新
7. 时间线只在写入时有点、块内断线 → 每秒固定记一点（连续曲线）
8. 会话外手动切换曾偷偷开 manual 会话（竞态+干扰开始）→ 改为无会话直接写驱动
9. 复位在会话外无效 → 改为任何状态都生效
10. 会话开始先写 800 再跳变 → 首块 sens 直接作为 SESSION_START
